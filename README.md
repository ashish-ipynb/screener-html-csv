# 📈 Screener HTML to CSV Converter

A Streamlit application that converts a manually downloaded **Screener Latest Quarterly Results** HTML page into a structured CSV.

## 🌐 Live App

**https://screener-html-csv.streamlit.app/**

## Features

- 📂 Upload a downloaded Screener HTML file
- 📊 Extract quarterly financial data
- 📈 Preserve positive and negative YoY growth values
- 📅 Add extraction timestamp
- 📥 Download structured CSV

## Installation

```bash
pip install -r requirements.txt
```

Run locally:

```bash
streamlit run app.py
```

## How to Use

1. Open Screener.
2. Navigate to **Latest Quarterly Results**.
3. Save the webpage as an HTML file.
4. Upload the HTML file to the application.
5. Download the generated CSV.
